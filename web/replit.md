# Prodinamik Engine v1.3 — Control Plane UI

A comprehensive 14-page admin dashboard for the Prodinamik pipeline engine. Built as a frontend-only React + Vite app that connects to an external engine instance via API key authentication.

## Run & Operate

- `pnpm --filter @workspace/prodinamik-ui run dev` — run the UI (port 21385)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- Required env: none (frontend-only, engine URL is user-configured at login)

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- UI: React 18 + Vite, wouter (routing), Zustand (state), Recharts (charts)
- Components: shadcn/ui (Radix-based), lucide-react icons, Tailwind CSS v4
- API client: generated hooks from `@workspace/api-client-react` (Orval + TanStack Query)
- Auth: API key (`pdmk_*`) + base URL stored in localStorage via Zustand persist

## Where things live

- `artifacts/prodinamik-ui/src/pages/` — all 14 page components
- `artifacts/prodinamik-ui/src/components/layout/` — AppLayout (sidebar + topbar)
- `artifacts/prodinamik-ui/src/store/` — auth.ts (Zustand, persisted), ui.ts (theme + sidebar)
- `artifacts/prodinamik-ui/src/lib/mock-data.ts` — realistic mock data for all types
- `lib/api-client-react/src/generated/api.ts` — all generated hooks
- `lib/api-spec/openapi.yaml` — OpenAPI spec (source of truth for API contract)

## Pages

1. `/login` — API key + base URL login
2. `/` — Dashboard (health, metrics, charts, alerts)
3. `/runs` — Run management table with filters and pagination
4. `/runs/:slug` — Run detail (tabs: overview, events, validation, context, debug)
5. `/state-machine` — SVG state machine viewer (admin)
6. `/observability` — Metrics, latency charts, audit feed
7. `/audit` — Full audit log with JSON/CSV export
8. `/ai` — AI dashboard (drift, emergence, forecasting, remediation)
9. `/plugins` — Installed plugins + marketplace
10. `/human-loop` — Approvals, budget management, pause control
11. `/config` — 12-section config editor with YAML preview (admin)
12. `/security` — API keys, RBAC matrix, rate limits (admin)
13. `/distribution` — Raft cluster status and peer management (admin)
14. `/chaos` — Fault injection scenarios with safety controls (admin)

## Architecture decisions

- **Frontend-only**: No backend — the app connects directly to an external Prodinamik engine instance. Engine URL and API key are stored in localStorage and injected into every request via `setBaseUrl()` and `setAuthTokenGetter()` from the generated client.
- **Mock data fallback**: All pages fall back to realistic mock data when the engine is unreachable, so the UI is fully usable as a demo without a live engine.
- **Dark mode default**: Theme is stored in Zustand/localStorage; applied via `.dark` class on `<html>`.
- **Admin-only routes**: State Machine, Config, Security, Distribution, and Chaos pages wrap their content in `<AdminRoute>` which checks the role from auth store.
- **Generated API client**: All API hooks are auto-generated by Orval from `lib/api-spec/openapi.yaml`. Do not edit the generated files — run codegen instead.

## Product

Users (platform engineers, SREs) connect the dashboard to their Prodinamik engine instance by providing an API key and base URL at login. From there they can monitor runs, manage pipelines, inspect audit logs, configure the engine, and run chaos experiments — all from a single dense information-rich control plane.

## User preferences

- No emojis in UI — use Lucide React icons only
- Dark mode by default, light mode available via toggle
- Monospace font for slugs, IDs, API keys, JSON, and code values
- Dense information layout — every pixel should earn its place

## Gotchas

- The `refetchInterval` option in TanStack Query v5 requires `as any` cast when passed alongside generated query key types
- `useResetBudget.mutate()` takes `undefined` (void mutation) — do not pass `{}`
- Vite does NOT type-check at dev time — always run `pnpm run typecheck` before assuming TypeScript is clean
- Never edit files in `lib/api-client-react/src/generated/` — these are auto-generated
