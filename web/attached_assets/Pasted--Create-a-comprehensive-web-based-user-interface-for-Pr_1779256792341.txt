Create a comprehensive web-based user interface for Prodinamik Engine v1.3, a product-agnostic pipeline engine with formal state machine, multi-tier validation, event sourcing, Raft consensus, plugin ecosystem, and AI-native features.

## PROJECT OVERVIEW

Prodinamik Engine is the shared core behind Content-OS, Haber-Kurator, and dev-cycle. It manages any production pipeline (content, software, research, design) through a unified state machine, validator pipeline, and distributed runtime. The engine has 49 Python modules, 333 tests, 46 CLI commands, and 4 production profiles (software, content, research, design).

## TECHNICAL STACK

- **Frontend Framework:** React 18+ with TypeScript
- **UI Library:** shadcn/ui (modern, accessible components)
- **State Management:** Zustand (lightweight, simple)
- **Routing:** React Router v6
- **HTTP Client:** Axios with interceptors
- **Real-time:** Native WebSocket with reconnection logic
- **Charts:** Recharts (for metrics and analytics)
- **Graph Editor:** React Flow (for state machine visualization)
- **Code Editor:** Monaco Editor (for YAML editing)
- **Forms:** React Hook Form with Zod validation
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Date Handling:** date-fns
- **Build Tool:** Vite

## BACKEND API INTEGRATION

The engine provides an HTTP server with the following endpoints (base URL configurable):

### Core Endpoints
- `GET /healthz` - Health check
- `GET /metrics` - Prometheus metrics (text format)
- `GET /api/v1/runs` - List all runs (requires auth)
- `POST /api/v1/runs` - Create new run (requires auth)
- `GET /api/v1/runs/{slug}` - Get run details (requires auth)
- `POST /api/v1/runs/{slug}/transition` - State transition (requires auth)
- `GET /api/v1/profiles` - List available profiles (requires auth)
- `GET /api/v1/audit` - Query audit log (requires auth)
- `GET /api/v1/metrics` - Engine metrics (requires auth)

### Human Loop Endpoints
- `GET /api/v1/human/approvals` - Pending approvals
- `POST /api/v1/human/approve` - Approve task
- `POST /api/v1/human/reject` - Reject task
- `POST /api/v1/human/pause` - Pause task
- `GET /api/v1/human/budget` - Budget status
- `POST /api/v1/human/budget/reset` - Reset budget
- `GET /api/v1/human/dashboard` - Oversight dashboard HTML

### Authentication
API key authentication via `Authorization: Bearer pdmk_xxxx` header. Roles: admin, user, readonly.

interface AppState {
  // Auth
  auth: {
    apiKey: string | null;
    role: 'admin' | 'user' | 'readonly' | null;
    isAuthenticated: boolean;
  };
  
  // Engine
  engine: {
    health: EngineHealth;
    degradation: 'FULL' | 'DEGRADED' | 'SURVIVAL';
    uptime: number;
  };
  
  // Runs
  runs: {
    list: Run[];
    selected: Run | null;
    filters: RunFilters;
    loading: boolean;
  };
  
  // State Machine
  stateMachine: {
    definition: StateMachineDefinition;
    validation: ValidationResult[];
    selectedNode: string | null;
    selectedEdge: string | null;
  };
  
  // Observability
  observability: {
    metrics: MetricData[];
    alerts: Alert[];
    auditLog: AuditEntry[];
  };
  
  // AI
  ai: {
    driftEvents: DriftEvent[];
    emergenceCandidates: EmergenceCandidate[];
    forecasts: ForecastData[];
    recommendations: Recommendation[];
    remediationPlans: RemediationPlan[];
    config: AIConfig;
  };
  
  // Plugins
  plugins: {
    list: Plugin[];
    installed: Plugin[];
    marketplace: Plugin[];
  };
  
  // Human Loop
  humanLoop: {
    approvals: ApprovalTask[];
    budget: BudgetStatus;
    audit: ApprovalAudit[];
  };
  
  // Config
  config: {
    yaml: string;
    envVars: Record<string, string>;
    validation: ConfigValidationResult[];
  };
  
  // UI
  ui: {
    theme: 'light' | 'dark';
    sidebarCollapsed: boolean;
    notifications: Notification[];
  };
