# Scaffolding

Prodinamik Engine v1.1 — Scaffolding Generator

Generates new profile modules and project scaffolds.
Usage: `prodinamik new profile <name>` or `prodinamik new project <name>`

**Module:** `engine.scaffold.py`

## Functions

### `generate_profile(name, output_dir)`

Generate a new profile module

### `generate_project(name, output_dir)`

Generate a new project scaffold

### `list_profiles(profile_dir)`

List available profile modules
